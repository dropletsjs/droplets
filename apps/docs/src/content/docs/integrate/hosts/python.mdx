## How this host is set up

The code is `examples/hosts/python-fastapi/shop.py` (a router `main.py` includes)
and the Jinja templates in `templates/shop/`.

### Pieces and ports

`docker-compose.yml` starts three services:

| Service | Port | What it is |
| --- | --- | --- |
| `web` | 8001, public | FastAPI: the shop's pages, the proxy, and the basic page at `/` |
| `shop` | 8300, internal only | the shop's droplets server (`examples/shop`) |
| `droplets` | 8000, public | the Svelte example's droplets server, for `/` only |

| On `web` | Value | Used for |
| --- | --- | --- |
| `SHOP_INTERNAL_URL` | `http://shop:8300` | internal: fragment fetches and the proxy |
| `SHOP_PUBLIC_URL` | `http://localhost:8001` | public: this host's own origin, sent as `x-host` |
| `DROPLETS_INTERNAL_URL`, `DROPLETS_PUBLIC_URL` | `http://droplets:8000`, `http://localhost:8000` | the same pair, for the basic page |

### How a page gets a droplet

A server fetch with `httpx`, all of a page's fragments at once
(`asyncio.gather`), printed by a Jinja template:

```python
# shop.py
async def fragment(request: Request, droplet: str, params: list[tuple[str, str]] | None = None) -> dict:
    url = f"{SHOP_INTERNAL_URL}/droplets/{quote(droplet, safe='')}?{urlencode(params or [])}"
    # The browser's request, as the shop should see it: its cookies, this page as the host.
    headers = {"accept": "text/html", "x-host": SHOP_ORIGIN, "referer": SHOP_ORIGIN + _raw_target(request)}
    cookie = request.headers.get("cookie")
    if cookie:
        headers["cookie"] = cookie
    response = await client.get(url, headers=headers)  # follow_redirects=False
    # Only a text/html answer becomes Markup; its Set-Cookie goes out with the
    # page, its Link preloads into <head>, a 3xx is answered as it is.
```

```jinja
{# templates/shop/gallery.html #}
<aside>{{ fragments[0] }}</aside>
```

`referer` is the page's path and query as the browser sent it: the
droplet's [`host`](/integrate/http-contract/#host-where-the-droplet-renders).
`templates/shop/layout.html` loads `<script type="module" src="/index.js">`
once, through the proxy, and each droplet hydrates itself. `render` fetches
the toasts and the header's cart badge with every page's fragments
(`asyncio.gather`); the `toast-center` fragment comes first in the body, and
`/index.js` installs `window.shopMessageQueue` before any droplet starts (the
shop's `src/hooks.client.ts`):

```jinja
<body class="shop">
{{ toasts }}
<header class="shop-header">…<div class="shop-cart">{{ cart }}</div>…</header>
```

### What it proxies

One handler on `/index.js`, `/droplets/{rest:path}` (fragments, `_data`,
form actions), `/assets/{rest:path}` and `/api/{rest:path}`, for every
method, passes the request to the shop with `x-host` written out and passes
the answer back: status, `Set-Cookie` and redirects untouched. The shop's
cookies (`cart_id`, `shop_admin`) are first-party, and nothing is
cross-origin; the shop sets them only from form actions and `/api`, which
come through here.

### The shop's environment

- `DROPLETS_TRUSTED_ORIGINS: http://localhost:8001`: the only origin whose
  [`x-host`](/integrate/http-contract/#x-host-the-public-location) and
  [form posts](/integrate/http-contract/#form-posts-the-origin-check) the shop accepts.
- `DROPLETS_SECRET`: signs a form's result on the redirect back to the page
  when JavaScript is off ([Post/Redirect/Get](/integrate/http-contract/#postredirectget)).
- `ADMIN_USER`, `ADMIN_PASSWORD`, `SHOP_SECRET`: the demo login
  (admin / droplets) and the key its cookie is signed with. Demo values only.

### Gotchas

- **The shared `httpx` client must not keep cookies.** Its default jar would
  store the first visitor's `cart_id` (or admin session) from a proxied
  answer and send it with everyone else's requests. The client gets a
  `CookieJar` that accepts no domain; the browser's `Cookie` header is
  forwarded as it is.
- **`Markup` only for the shop's HTML.** Jinja escapes everything else; the
  "unavailable" note is built with `Markup.format`, so the droplet's id is
  escaped. See [For hosts](/guides/security/#for-hosts).

### Run it

```bash
cd examples/hosts/python-fastapi
docker compose up --build
open http://localhost:8001/gallery   # log in as admin / droplets
```

## The Svelte example

The same app serves the Svelte example at `/`: its three droplets, one per mode, from `examples/frameworks/svelte` (the `droplets` service).

No JavaScript on the host: Python fetches the fragments and a template prints
them.

```python
DROPLETS_INTERNAL_URL = os.environ.get("DROPLETS_INTERNAL_URL", "http://localhost:8000")
DROPLETS_PUBLIC_URL = os.environ.get("DROPLETS_PUBLIC_URL", "http://localhost:8000")

async def fetch_droplet(client: httpx.AsyncClient, droplet: str, **props: str) -> Markup:
    query = f"?{urlencode(props)}" if props else ""
    response = await client.get(
        f"{DROPLETS_INTERNAL_URL}/droplets/{droplet}{query}",
        headers={"x-host": DROPLETS_PUBLIC_URL},
        timeout=5.0,
    )
    response.raise_for_status()
    return Markup(response.text)   # trusted markup from our own server; do not escape

FRAMEWORKS = ["svelte", "vue", "react", "solid", "handlebars"]

@app.get("/", response_class=HTMLResponse)
async def index(request: Request, who: str = "FastAPI"):
    async with httpx.AsyncClient() as client:
        fragments = await asyncio.gather(
            *(fetch_droplet(client, f"{framework}-ssr-hydrate", who=who) for framework in FRAMEWORKS)
        )
    return templates.TemplateResponse(request, "index.html", {
        "droplets_public_url": DROPLETS_PUBLIC_URL,
        "fragments": fragments,
    })
```

```html
<script type="module" src="{{ droplets_public_url }}/index.js"></script>
...
{% for fragment in fragments %}
  {{ fragment }}
{% endfor %}
```

`Markup` marks the fragment as safe so Jinja does not escape it. The same
pattern works with Flask, Django or anything else that can make an HTTP
request and print a string.

The example lives in `examples/hosts/python-fastapi`. The page and the droplets
server are different origins, so the droplets server runs with `cors: true`.
