## How this host is set up

The code is `examples/hosts/express/src/shop.js`, mounted by `src/server.js`.

### Pieces and ports

`docker-compose.yml` starts three services:

| Service | Port | What it is |
| --- | --- | --- |
| `web` | 8003, public | Express: the shop's pages, the proxy, and the basic page at `/` |
| `shop` | 8300, internal only | the shop's droplets server (`examples/shop`) |
| `droplets` | 8000, public | the Svelte example's droplets server, for `/` only |

| On `web` | Value | Used for |
| --- | --- | --- |
| `SHOP_INTERNAL_URL` | `http://shop:8300` | internal: fragment fetches and the proxy |
| `SHOP_PUBLIC_URL` | `http://localhost:8003` | public: this host's own origin, sent as `x-host` |
| `DROPLETS_INTERNAL_URL`, `DROPLETS_PUBLIC_URL` | `http://droplets:8000`, `http://localhost:8000` | the same pair, for the basic page |

### How a page gets a droplet

A server fetch. Each route fetches its fragments in parallel (`Promise.all`,
with the toasts and the header's cart badge) and pastes them into one template-string layout:

```js
// src/shop.js
const fragmentHeaders = (req) => {
  const headers = { accept: "text/html", "x-host": origin, referer: origin + req.originalUrl };
  const cookie = req.get("cookie");
  if (cookie) headers.cookie = cookie;
  return headers;
};

const response = await fetch(`${internal}/droplets/${encodeURIComponent(id)}?${params}`, {
  headers: fragmentHeaders(req),
  redirect: "manual",
});
// Only a text/html answer is pasted. Its Set-Cookie goes out with the page,
// its Link preloads into <head>, and a 3xx is answered as it is.
```

`referer` is the page's own URL, query included: that is the droplet's
[`host`](/integrate/http-contract/#host-where-the-droplet-renders), and after a
post without JavaScript it carries the form's result. The layout loads
`<script type="module" src="/index.js">` once, through the proxy, and each
droplet hydrates itself. The `toast-center` fragment comes first in the body;
`/index.js` installs `window.shopMessageQueue` before any droplet starts (the
shop's `src/hooks.client.ts`):

```js
// src/shop.js, layout()
<body class="shop">
${toasts}
<header class="shop-header">…<div class="shop-cart">${cart}</div>…</header>
```

### What it proxies

`/index.js`, `/droplets/*` (fragments, `_data`, form actions), `/assets/*`
and `/api/*` go to the shop through one router (`router.use(path, proxy)`):
bodies streamed, `x-host` written out, redirects not followed, and
`Set-Cookie` passed back untouched. The browser only ever talks to
`localhost:8003`, so there is no CORS, and the shop's cookies (`cart_id`,
`shop_admin`) are first-party. The shop sets them only from form actions and
`/api`, which always come through here.

### The shop's environment

- `DROPLETS_TRUSTED_ORIGINS: http://localhost:8003`: the only origin whose
  [`x-host`](/integrate/http-contract/#x-host-the-public-location) and
  [form posts](/integrate/http-contract/#form-posts-the-origin-check) the shop accepts.
- `DROPLETS_SECRET`: signs a form's result on the redirect back to the page
  when JavaScript is off ([Post/Redirect/Get](/integrate/http-contract/#postredirectget)).
- `ADMIN_USER`, `ADMIN_PASSWORD`, `SHOP_SECRET`: the demo login
  (admin / droplets) and the key its cookie is signed with. Demo values only.

### Gotchas

- **The proxy drops `content-encoding` and `content-length`.** `fetch` has
  already decoded the body, so passing them on would lie to the browser.
- **Off localhost, use https.** The shop's cookies are `Secure` everywhere
  except plain HTTP to `localhost`. `docker-compose.https.yml` puts Caddy in
  front on `https://127-0-0-1.sslip.io:8443` (see
  `examples/hosts/express/README.md`), and `pnpm test:hosts express --https`
  checks the cookies arrive `Secure`.
- The page is `private, no-store`: its fragments were rendered with the
  visitor's cookies. See [For hosts](/guides/security/#for-hosts).

### Run it

```bash
cd examples/hosts/express
docker compose up --build
open http://localhost:8003/gallery   # log in as admin / droplets
```

## The Svelte example

The same app serves the Svelte example at `/`: its three droplets, one per mode, from `examples/frameworks/svelte` (the `droplets` service).

Two ways to combine Express with droplets.

### 1. Express as a host

The droplets server runs as its own process. Express fetches `GET /droplets/<id>`
for each droplet, with `x-host` set to the browser-facing origin, and renders
the fragments into its page.

```js
export function createDropletClient({ internalUrl, publicUrl }) {
  async function fragment(droplet, props = {}) {
    const url = new URL(`/droplets/${encodeURIComponent(droplet)}`, internalUrl);
    for (const [key, value] of Object.entries(props)) url.searchParams.set(key, String(value));
    const response = await fetch(url, { headers: { "x-host": publicUrl } });
    if (!response.ok) return `<p class="error">droplet "${droplet}" unavailable</p>`;
    return response.text();
  }
  const clientScript = `<script type="module" src="${publicUrl}/index.js"></script>`;
  return { fragment, clientScript };
}
```

```js
const droplets = createDropletClient({
  internalUrl: process.env.DROPLETS_INTERNAL_URL ?? "http://localhost:8000",
  publicUrl: process.env.DROPLETS_PUBLIC_URL ?? "http://localhost:8000",
});

const FRAMEWORKS = ["svelte", "vue", "react", "solid", "handlebars"];

app.get("/", async (req, res) => {
  const who = req.query.who ?? "Express";
  const fragments = await Promise.all(
    FRAMEWORKS.map((framework) => droplets.fragment(`${framework}-ssr-hydrate`, { who })),
  );
  res.type("html").send(layout({ body: fragments.join(""), clientScript: droplets.clientScript }));
});
```

Browsers load each droplet's JavaScript from the droplets origin, so it runs
with `cors: true`.

### 2. One process

`vite build` emits `dist/server.js`, which exports `{ fetch }` and does not
listen on its own when imported. Express mounts it as a request listener, so
droplet routes and Express routes share one origin: no CORS, no `x-host`, and
the page can even call `fetch()` in-process to render fragments without an
HTTP round trip.

```js
import express from "express";
import { getRequestListener } from "@hono/node-server";

const droplets = (await import("../../frameworks/svelte/dist/server.js")).default;
const app = express();

app.get("/", async (req, res) => {
  const origin = `${req.protocol}://${req.get("host")}`;
  const fragment = async (id) =>
    (await droplets.fetch(new Request(new URL(`/droplets/${id}`, origin)))).text();

  res.type("html").send(layout({
    body: (await fragment("ssr-hydrate")) + (await fragment("ssr-nohydrate")),
    clientScript: '<script type="module" src="/index.js"></script>',
  }));
});

// Everything else is a droplets route: /droplets/*, /droplets/<id>/client.js, /assets/*, /api/* ...
app.use(getRequestListener(droplets.fetch));
app.listen(8003);
```

Both variants are in `examples/hosts/express` in the repository: `docker compose
up --build` for the first, `node src/embedded.js` for the second.
