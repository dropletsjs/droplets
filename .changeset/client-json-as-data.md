Client JSON reaches user code as data: props and `form` from a JSON body and props from `x-droplet-props` are copied into ordinary objects without an own `__proto__` key, refused past 64 levels of nesting; a body is JSON by its parsed media type (`application/json` or `+json`), the same reading the size limit uses. An unknown action's name is echoed in the 404 only when it is one an action could have. What no handler caught answers through `handleError`, as every other error does, and an endpoint's log line names its path once.
